<interactions-timeline>

GitHub npm Bram.us

An encapsulated Web Component (<interactions-timeline>) that records CSS animations, CSS transitions, Web Animations API (element.animate()) calls, Scroll-Driven Animations (ScrollTimeline & ViewTimeline), scroll positions, user interactions, and DOM element removals—then pauses the page and lets you scrub backward and forward through the page’s visual history in a collapsible, resizable bottom sheet.

3. Web Animations API (element.animate())

Installation & Usage

Drop <interactions-timeline> into any page to inspect and scrub its animations, transitions, and scroll interactions.

Quick Start ESM / NPM 
<script type="module" src="interactions-timeline"></script>

<!-- Optional: explicitly place the custom element (auto-injected if omitted) -->
<interactions-timeline></interactions-timeline>

JavaScript API

In addition to the injected top-right recording button and interactive bottom-sheet scrubber, you can control <interactions-timeline> programmatically:

Programmatic Control Methods & Properties 
const visualizer = document.querySelector('interactions-timeline');

// Start and stop recording programmatically
visualizer.startRecording();
const store = visualizer.stopRecording();

// Scrub the page (animations, transitions, and scrollers) to 450ms
visualizer.scrubToTime(450);

// Close or reset the visualizer and unpause all page animations
visualizer.closeVisualizer();
visualizer.reset();
